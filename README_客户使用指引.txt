--------------------------------------------------------------------------------
一、 快速上手步骤
--------------------------------------------------------------------------------
1. 解压本压缩包到电脑的任意位置（如桌面或 D 盘）；
2. 双击打开【FlashCraft_桌面自动化工作台.exe】；
3. 【选择文件/目录】：
   - 方式 A：直接从桌面或微信中，将待处理的 Excel/CSV 表格或文件夹【拖拽】到软件窗口中；
   - 方式 B：点击界面右侧的“选择单个表格”或“选择批量目录”按钮；
4. 点击底部【🚀 开始执行任务】按钮，软件将自动以毫秒级速度处理；
5. 处理完成后，系统会自动为您打开生成的成果 Excel 表格文件夹。

--------------------------------------------------------------------------------
二、 常见问题排查（重要！）
--------------------------------------------------------------------------------
Q1: 双击运行时，Windows 弹出蓝色窗口提示“Windows 已保护你的电脑”？
A1: 这是 Windows 系统对所有没有购买昂贵企业数字证书的个人软件的默认拦截，请放心使用。
    解决办法：点击提示窗口中的【更多信息】，然后点击右下角的【仍要运行】即可正常打开。

Q2: 提示“文件被占用或权限受限”？
A2: 请检查您选择的原始表格或目标结果表格是否正在被 Excel、WPS 等软件打开。
    关闭相关软件的表格窗口后，再次点击运行即可。

Q3: 处理后的文件保存在哪里？
A3: 默认保存在您电脑的【桌面】->【FlashCraft_处理结果】文件夹中。
    您也可以随时点击软件界面中的【📁 打开输出目录】按钮直达该文件夹。

Q4: 试用版与正式版区别？
A4: 试用演示版本单次仅导出前 10 行数据供您验收准确度与逻辑；
    结清尾款后，技术人员将为您直接发送【全量无限制正式版】。
